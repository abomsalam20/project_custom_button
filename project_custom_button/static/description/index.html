Project Custom Button

Add powerful custom action buttons to your Project module with one click workflow automation

Odoo 16, 17, 18 Community & Enterprise No Coding Required

● Overview

The Project Custom Button Module enhances the Odoo Project app by adding fully configurable smart buttons directly on Project and Task forms. Perfect for quick actions like Create Invoice, Start Timesheet, Duplicate Project, Send Report, or any custom server action you need. Save time and streamline your project workflow without modifying core Odoo code.

● Key Features

⚡
One-Click Actions

Add custom buttons on project.project and project.task views. Execute Python code, server actions, or open wizards instantly.

🎯

Control button visibility by user groups, project stage, state, or custom domain. Buttons show only when relevant.

🎨

Choose icon, color, label, sequence, tooltip. Supports Font Awesome & Odoo Icons. No development needed for basic setup.

🔒
Access Control

Restrict buttons to Project Manager, User, or custom security groups. Secure by design.

🔧

Link to window actions, server actions, URL actions, client actions. Works with automated actions and webhooks.

📱
Responsive

Works perfectly on Odoo Backend, Odoo Mobile App, and new OWL views. Compatible with Odoo 16/17/18.

How It Works

  1. Install the module from Apps menu
  2. Go to Project > Configuration > Custom Buttons
  3. Create new button: set Name, Model (project.project / project.task), Icon
  4. Define Action – select existing Action or write simple Python code
  5. Set Conditions – who sees it and when
  6. Save & Refresh – button appears instantly!
